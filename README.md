## English

### What is RESONANCE?

RESONANCE is a minimalist timing-based mini-game built as a single HTML file.  
You control a luminous core with your mouse and emit expanding pulses by clicking. The goal is to hit floating orbs with precision — the closer the pulse is to the orb at the moment of contact, the higher the score and the stronger your combo.

It was designed to feel clean, responsive and slightly tense. No tutorials, no clutter, just you, the pulse, and the timing.

### Features

- Pure vanilla HTML + CSS + JavaScript (no frameworks, no build step)
- Smooth core movement with intentional lag for a sense of weight
- Expanding pulse mechanic with accuracy-based scoring
- Combo system that rewards consecutive precise hits
- Lightweight particle effects on successful hits and misses
- Dark interface with cyan & magenta accents
- Fully responsive (works on desktop)

### How to Play

1. Move the mouse — the core follows with a slight delay
2. Click to emit a pulse
3. Time the pulse so it touches the orbs as accurately as possible
4. Build combos by hitting multiple orbs in sequence
5. Let too many orbs accumulate and the signal is lost

### Controls

| Action          | Input     |
|-----------------|-----------|
| Move core       | Mouse     |
| Emit pulse      | Left Click|

### Running the Game

1. Download or copy the `resonance.html` file
2. Open it directly in any modern browser
3. That’s it. No installation, no server needed.

### Technical Notes

- Single file, zero dependencies
- Canvas-based rendering
- RequestAnimationFrame game loop
- Lightweight particle system
- Score and combo updated in real time

## Português (Brasil)

### O que é o RESONANCE?

RESONANCE é um mini-jogo minimalista de timing feito em um único arquivo HTML.  
Você controla um núcleo luminoso com o mouse e emite pulsos expansivos ao clicar. O objetivo é acertar os orbes flutuantes com precisão — quanto mais perto o pulso estiver do orbe no momento do contato, maior a pontuação e mais forte o combo.

Foi pensado para ser limpo, responsivo e levemente tenso. Sem tutoriais, sem distrações. Só você, o pulso e o timing.

### Características

- HTML + CSS + JavaScript puro (sem frameworks, sem build)
- Movimento suave do núcleo com atraso proposital (sensação de peso)
- Mecânica de pulso expansivo com pontuação baseada em precisão
- Sistema de combo que recompensa acertos consecutivos
- Efeitos de partículas leves em acertos e erros
- Interface escura com detalhes em ciano e magenta
- Totalmente responsivo (funciona bem no desktop)

### Como Jogar

1. Mova o mouse — o núcleo segue com um leve atraso

3. Acerte os orbes no momento mais preciso possível
4. Construa combos acertando vários orbes em sequência
5. Deixe muitos orbes acumularem e o sinal é perdido
